Executive summary

실제 SGLang serving에서도
FP4 적용으로 최대 3.47× 빨라졌다

1.00×
BF16 baseline

Linear: BF16 · KV-cache: BF16
Attention: FlashInfer prefill + XQA decode

3.28×
W4A4 linear 적용

BF16 KV · attention backend 동일

3.47×
W4A4 + NVFP4 KV

KV-cache까지 NVFP4로 변경
QK/PV는 FP4 Core 미사용 · memory −51.6%

핵심: 같은 FlashInfer prefill + TRTLLM MHA/XQA decode에서 FP4-Core linear만으로 1.00× → 3.28×, NVFP4 KV를 더해 3.47× (+5.8%)가 됐다. 조건은 prefill-heavy 2048→128 · concurrency 32 · output throughput.
GSM8K는 77.0% (BF16) → 68.5% (W4A4 + BF16 KV) → 64.5% (W4A4 + NVFP4 KV)로 하락했다.
